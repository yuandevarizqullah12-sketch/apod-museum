    Object information

    WISE 0855−0714 (WISE J085510.83−071442.5), a very cold brown dwarf, used here as the test target. Reference position below is derived from the catalog designation (J2000), not measured by SPHEREx, and I could not confirm it against the official challenge page; edit it if the challenge lists other values.

    Catalog reference (from designation): RA 133.79513°, Dec −7.24514°. The object has large proper motion, so its position today differs from this catalog position; use a radius of a few hundredths of a degree or more. Measured data (search results) and catalog reference are kept separate; this page does not claim any object motion.
